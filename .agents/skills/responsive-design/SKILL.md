# Responsive Design

Use existing WARNOTO breakpoints and tokens as authoritative. Prefer mobile-first styles, content-based breakpoints, fluid typography/spacing, intrinsic Grid/Flex layouts, container queries where supported, logical properties, responsive media, and accessible 44px touch targets. Check for horizontal overflow, fixed-width traps, mobile viewport-height issues, small text, distorted images, and stacking/z-index problems. Read `.claude/skills/responsive-design/references/details.md` only when a pattern needs deeper guidance. Do not introduce dependencies or redesign the styling architecture.
